# Everything, *step by step*

How to install LucidCore on your Emby server and set up each feature. Written for people who run a server at home, not for programmers.

## Start here

Installing LucidCore takes a few minutes:

1. Download one file, LucidCore.dll, and put it in Emby’s plugins folder.
2. Restart Emby, then paste your license key in the plugin and select Verify License.
3. Switch on the features you want, save and restart Emby.

The [install guide](installation.md) walks you through each step, with the usual folder locations for Windows, Linux and Docker.

## The five features

- [LucidSearch](lucidsearch.md)

  Find films and shows in your library by their alternative names, in the languages you choose. Results come from a fast index on your server.

- [LucidPush](lucidpush.md)

  Pop-up messages in the Emby apps, sent by rules you set or straight from your own scripts through its API.

- [Seerr requests](seerr-integration.md)

  Search can show title information outside your library. Press the heart to send a request to your Seerr request manager.

- [LucidTop](lucidtop.md)

  A Recommended for you row for each person on the home screen, plus trending and top rated rows from your own library.

- [LucidFlow](lucidflow.md)

  An AI sorts Seerr requests between your connected servers, using your descriptions. It handles requests from Emby and Seerr.

## Where the settings live

Everything is set up in one place in Emby: **Dashboard › Plugins › LucidCore**. The page has a tab for each feature: Overview, Search, Seerr, LucidTop, LucidFlow, LucidPush, and Help.

> [!NOTE]
> Switching a feature on or off in the Overview tab takes effect after Emby restarts. The other settings apply as soon as you save.
